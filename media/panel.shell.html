Tab autocomplete

Prefetch while typing (ghost stays hidden). Ctrl+Enter / ⌘⏎ shows the suggestion; Tab accepts. Prefer coder models.

Coder models usually give better inline fills than chat/flash models.

Up to N distinct ghost texts per request. Cycle Alt+[ / Alt+]; Tab accepts the current one.

One glob per line. Tab stays silent on matches (dist, generated, …). Clear all lines to allow every path.

After Tab accept, show a Next chip at the likely following edit (store → events, event → .on). Tab jumps; Esc dismisses.

Chip = silent prefetch + ⌘⏎. Inline = ghost text appears automatically.

Use prompt+suffix fill-in-the-middle when the provider supports it. Falls back to chat hole-fill.
