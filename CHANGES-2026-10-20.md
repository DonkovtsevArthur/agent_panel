# Harbor Agents — изменения за 20.10.2026 (≈ 21:20–23:20)

Текущие версии: **VS Code 2.9.102**, **WebStorm 2.1.79**.

## Коммит 2.9.95 (22:11)

1. **Поповер «Контекст».** У кольца заполненности рядом с полем ввода открывается разбивка того, чем занято окно модели в последнем запросе: сообщения, системные и MCP-инструменты, системный промпт, скиллы, память и правила, инструкции MCP, буфер автосжатия, свободное место.
2. **Параллельные чаты больше не мешают друг другу.** Если в двух чатах одновременно идёт работа, служебные данные хода не перетекают между ними: проверка правок, просмотр картинок, приложенные к ходу изображения.
3. **Git только по явной просьбе.** Агент делает `git commit` / `git push` через терминал, только если об этом прямо попросили в текущем сообщении. Автоподтверждение команд само по себе этого больше не разрешает.

## После коммита (22:15–23:15, не закоммичено)

### Поповер «Контекст» — доработки

4. Открывается при наведении мыши и закрывается, когда мышь уходит. Клик закрепляет поповер.
5. Проценты считаются от порога автосжатия, а не от всего окна модели: «Использовано N % до автосжатия» и «Автосжатие на X из окна Y».
6. Внутри появилась статистика: сколько токенов в последнем запросе и какая доля из кэша, а также итог по чату (вход, выход, кэш).
7. Файлы правил отображаются правильно: настоящие файлы с путями, а не разделы внутри AGENTS.md.
8. Разбивка сохраняется в чате и не пропадает после перезагрузки окна или IDE и при переключении между чатами.
9. Полоска заполненности корректно рисуется в VS Code.

### MCP

10. **«Ленивые» MCP-инструменты**, новая настройка. Каждый MCP-сервер (Jira, Confluence, Figma и свои) отправляется модели только списком названий инструментов. Полное описание подгружается, когда сервер реально нужен, поэтому неиспользуемые серверы почти не занимают место в запросе.

### Настройки

11. В WebStorm настройки при повторном открытии остаются на том разделе, где ты был, и больше не прыгают на «Модели».

### Модели и провайдеры

12. Новые модели добавляются **выключенными**.
13. При загрузке моделей из API больше нет галочек для выбора.
14. **Загрузка из API синхронизирует список с провайдером:**
    - новые модели добавляются (выключенными);
    - модели, которых провайдер больше не отдаёт, удаляются (до применения показаны красным и зачёркнутыми);
    - остальные не меняются: свитч, избранное и настройки сохраняются;
    - если провайдер вернул пустой ответ, ничего не удаляется.
15. Кнопка **«Удалить все модели провайдера»** с подтверждением прямо в панели.
16. Можно остаться совсем без моделей: встроенные модели по умолчанию больше не возвращаются сами.
