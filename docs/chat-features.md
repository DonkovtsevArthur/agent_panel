# Возможности чата — идеи и план

Документ собирает предложения по развитию чата Agent Panel.  
Принцип панели: данные никуда не утекают — всё локально, наружу только выбранный API.

## Уже есть

- Стриминг ответа и остановка генерации
- Отправка по Enter (Shift+Enter — новая строка)
- Выбор модели, избранные модели сверху
- Лёгкий markdown (заголовки, жирный, инлайн-код, code fences)
- Копирование сообщения и блоков кода
- Tools: `list_files`, `read_file`, `write_file`, `run_command`
- Контекст редактора (активный файл, курсор, выделение, вкладки)
- Индикатор использования контекстного окна
- Карточка изменённых файлов и переход в Source Control
- Локальные сессии агентов / чатов по workspace

## Предложения

### 1. Копирование ✅

- [x] Кнопка «Копировать» у сообщения user (сверху справа, вне пузыря)
- [x] Копирование блока кода одним кликом из fence
- [x] Тост / краткий статус «Скопировано»

### 2. Редактирование своего сообщения ✅

- [x] Клик по user-сообщению открывает редактирование
- [x] После правки — переотправка с этой точки
- [x] Можно сменить модель перед переотправкой
- [x] Сообщения ниже точки правки удаляются

### 3. Regenerate ✅

- [x] Перегенерировать последний ответ ассистента той же моделью
- [ ] Опционально: выбрать другую модель перед regenerate
- [x] Замена предыдущего ответа

### 4. Вложения и картинки ✅

- [x] Прикрепить файл(ы) из workspace к сообщению
- [x] Drag-and-drop файла в composer
- [x] Вставка изображений (если API провайдера поддерживает vision)
- [x] Превью вложений в bubble сообщения

### 5. @-упоминание файлов

- В composer: `@` → быстрый поиск файлов workspace
- В запрос уходит путь + (по желанию) содержимое / фрагмент
- Подсветка выбранных `@file` в тексте сообщения

### 6. Ветвление диалога

- «Ответвить» от любого сообщения
- Отдельная ветка чата без потери основной
- Переключение между ветками в UI

### 7. Поиск по чату

- Поиск по тексту текущего агента / всем агентам workspace
- Подсветка совпадений и переход к сообщению
- Фильтры: только user / только assistant / по дате

### 8. История tool-call’ов ✅

- [x] В ответе ассистента — раскрываемый список вызовов tools
- [x] Для каждого: краткая строка (имя / путь / команда)
- [ ] Возможность открыть затронутый файл из tool-call

## Заметки по реализации

- UI — webview (`media/panel.js` / `panel.css`)
- Логика агента — `src/agentLoop.ts`, tools — `src/tools.ts`
- Сессии — `src/sessionStore.ts` (локально, без облака)
- Новые фичи не должны слать данные куда-либо кроме выбранного `baseUrl` / провайдера
